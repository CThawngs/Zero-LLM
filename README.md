# Overview
**ZeroLLM** is a comprehensive, real-time leaderboard and directory of 100% free LLM providers and models. Built as a high-impact solution for the **Google AI Riser Vietnam 2026** Hackathon and powered by **Google's Antigravity** AI assistant and **Google AI Studio**, ZeroLLM empowers developers, researchers, and creators to discover, evaluate, and integrate free AI models effortlessly without credit card barriers.

## Purpose
### Target:
- Help developers, students, startup builders, and creators find and access completely free LLM APIs, rate limits, and context windows instantly.
- Eliminate the friction of discovering reliable free AI tiers across Google AI Studio, Groq, OpenRouter, Mistral, GitHub Models, Cloudflare, and more.
- Demonstrate a production-ready, full-stack application built with the "Vibe Coding" workflow (**Prompt → Build → Ship**) using **Google Antigravity**, **Google AI Studio**, and **Google Cloud Run**.

### Benefits:
- **Productivity:** Save hours of manual research by comparing model context lengths, RPM/RPD rate limits, and multimodal capabilities on a unified real-time dashboard.
- **Quality:** Automated real-time discovery engine powered by the **latest Google Gemini Flash models** (dynamic auto-resolution + Google Search Grounding) to continuously verify provider statuses, documentation, and newly released models without obsolescence.
- **Technology:** A modern, robust full-stack architecture built with **Next.js 15 (App Router) + TypeScript**, styled with **Tailwind CSS**, integrated with **Latest Google Gemini Flash (auto-updating model resolver & live web search)**, **Supabase** for persistent cloud synchronization, and deployed seamlessly on **Google Cloud Run**.

## View website at: [ZeroLLM](https://zero-llm.ai.studio)

## Key Features
- ⚡ **Realtime Free LLM Directory & Leaderboard** — Track 100% free AI providers (Google Gemini, Groq, OpenRouter, Mistral, Cerebras, Sambanova, GitHub Models, Cloudflare Workers AI) with live token limits, RPM/RPD quotas, and active status.
- 🤖 **Future-Proof Gemini Flash Auto-Discovery Scanner** — Autonomous background agent utilizing the **latest Google Gemini Flash model** (with dynamic model version resolution and Google Search grounding) to scan, verify, and ingest the latest free models and documentation in real time as AI evolves.
- 🔍 **Advanced Multi-Dimensional Filtering** — Search and filter by context capacity (>32k, 128k, 1M+ tokens), multimodal/vision support, reasoning capabilities, coding focus, and zero-credit-card requirements.
- 📊 **Interactive Analytics & Distribution Charts** — Visualized insights powered by Recharts and D3 for context window distributions, top providers, and model capability matrices.
- 🔑 **Interactive API Key Setup Guides** — Step-by-step instructions and direct portal links to acquire free API keys with zero friction.
- 🔄 **Supabase Real-Time Cloud Sync** — Robust real-time database synchronization with in-memory resilient fallback for uninterrupted uptime.
- 🌐 **Full Bilingual Support & Dark/Light Theme** — Seamless switching between English and Vietnamese interfaces with eye-safe modern dark and light aesthetics.

# Tổng quan
**ZeroLLM** là bảng xếp hạng và danh mục thời gian thực toàn diện về các nhà cung cấp và mô hình LLM hoàn toàn miễn phí (100% Free). Được xây dựng cho cuộc thi **Google AI Riser Vietnam 2026** và hỗ trợ toàn diện bởi trợ lý AI **Google Antigravity** cùng **Google AI Studio**, ZeroLLM giúp lập trình viên, nhà nghiên cứu và các nhà sáng tạo dễ dàng khám phá, đánh giá và tích hợp các mô hình AI miễn phí mà không gặp rào cản thẻ tín dụng.

## Mục đích
### Mục tiêu:
- Giúp các nhà phát triển, sinh viên, startup và người sáng tạo nhanh chóng tìm kiếm và tiếp cận các API LLM miễn phí, thông số context window và giới hạn quota (RPM, RPD).
- Xóa bỏ rào cản tìm kiếm các gói Free Tier uy tín giữa hàng loạt nhà cung cấp như Google AI Studio, Groq, OpenRouter, Mistral, GitHub Models, Cloudflare,...
- Minh chứng cho một giải pháp full-stack hoàn chỉnh được xây dựng theo quy trình "Vibe Coding" hiện đại (**Prompt → Build → Ship**) với **Google Antigravity**, **Google AI Studio** và triển khai trên **Google Cloud Run**.

### Lợi ích:
- **Năng suất:** Tiết kiệm hàng giờ tra cứu thủ công nhờ bảng so sánh trực quan đa chiều về độ dài ngữ cảnh, giới hạn request/phút, request/ngày và tính năng chuyên biệt.
- **Chất lượng:** Tích hợp công cụ quét và xác thực tự động được hỗ trợ bởi **mô hình Google Gemini Flash mới nhất** (tự động cập nhật theo thời gian thực + Google Search Grounding) để liên tục rà soát trạng thái hoạt động, tài liệu và các model vừa ra mắt mà không bao giờ bị lỗi thời.
- **Công nghệ:** Kiến trúc full-stack hiện đại với **Next.js 15 (App Router) + TypeScript**, giao diện **Tailwind CSS**, xử lý AI thông minh qua **Google Gemini Flash mới nhất (cơ chế phân giải phiên bản linh hoạt & tìm kiếm web thời gian thực)**, đồng bộ cơ sở dữ liệu với **Supabase**, và vận hành tối ưu trên hạ tầng **Google Cloud Run**.

- 🔍 **Bộ Lọc & Tìm Kiếm Đa Chiều Nâng Cao** — Lọc tức thì theo độ dài context (>32k, 128k, 1M+ tokens), hỗ trợ đa phương thức (Multimodal/Vision), mô hình suy luận (Reasoning), lập trình (Coding), và không yêu cầu thẻ tín dụng.

- 🔑 **Hướng Dẫn Lấy API Key Chi Tiết** — Hướng dẫn từng bước và liên kết trực tiếp tới trang cấp khóa API miễn phí của từng nhà cung cấp.

- 🌐 **Hỗ Trợ Song Ngữ Toàn Diện & Chế Độ Sáng/Tối** — Chuyển đổi mượt mà giữa tiếng Anh và tiếng Việt cùng giao diện Dark/Light tối ưu thị giác.
