# Overview
**ZeroLLM** is a comprehensive, real-time directory and aggregator of AI providers that offer 100% free Large Language Model (LLM) access on the market. Built as a high-impact solution for the **Google AI Riser Vietnam 2026** Hackathon and powered by **Google's Antigravity** AI assistant and **Google AI Studio**, ZeroLLM aggregates and indexes zero-cost LLM API providers, empowering developers, researchers, and creators to discover and access free AI models effortlessly without credit card barriers.

> **Note on Core Purpose:** ZeroLLM is an **aggregator and directory of providers offering free LLM models**, continuously updated in real-time by Google's latest Gemini Flash model (**Gemini-3.7-Flash** / dynamic future-proof Flash resolver). It is not a benchmark or model ranking leaderboard, but a practical directory connecting developers with verified free AI provider endpoints and quotas.

## Purpose
### Target:
- Aggregate and index AI providers offering free LLM APIs, rate limits (RPM/RPD), and context windows in a clean, unified platform.
- Eliminate the friction of discovering reliable free AI tiers across Google AI Studio, Groq, OpenRouter, Mistral, GitHub Models, Cloudflare Workers AI, Cerebras, SambaNova, and more.
- Demonstrate a production-ready, full-stack application built with the "Vibe Coding" workflow (**Prompt → Build → Ship**) using **Google Antigravity**, **Google AI Studio**, and **Google Cloud Run**.

### Benefits:
- **Productivity:** Save hours of manual research by viewing all free LLM providers, token quotas, and endpoint guides on a unified real-time dashboard.
- **Quality:** Automated real-time discovery engine powered by the **latest Google Gemini Flash models (Gemini-3.7-Flash + live Google Search Grounding)** to continuously verify provider statuses, documentation, and newly released models without obsolescence.
- **Technology:** A modern, robust full-stack architecture built with **Next.js 15 (App Router) + TypeScript**, styled with **Tailwind CSS**, integrated with **Latest Google Gemini Flash (auto-updating model resolver & live web search)**, **Supabase** for persistent cloud synchronization, and deployed seamlessly on **Google Cloud Run**.

## View website at: [ZeroLLM](https://zero-llm.ai.studio)

## Key Features
- ⚡ **Realtime Free LLM Provider Directory** — Comprehensive directory aggregating 100% free AI providers (Google AI Studio, Groq, OpenRouter, Mistral, Cerebras, SambaNova, GitHub Models, Cloudflare Workers AI) with live token limits, RPM/RPD quotas, and active status.
- ⚡ **Dynamic New Discoveries Engine** — Real-time tracking of newly discovered models and providers. Newly added models are automatically prioritized and pushed to **#1 (Top Rank)**, while older items shift down chronologically with live countdown timers and relative timestamps.
- 🤖 **Future-Proof Gemini Flash Auto-Discovery Scanner** — Autonomous background agent utilizing the **latest Google Gemini Flash model (Gemini-3.7-Flash)** (with dynamic model version resolution and Google Search grounding) to scan, verify, and ingest the latest free models and documentation in real time as AI evolves.
- 🔍 **Advanced Multi-Dimensional Filtering** — Search and filter by context capacity (>32k, 128k, 1M+ tokens), multimodal/vision support, reasoning capabilities, coding focus, and zero-credit-card requirements.
- 📊 **Interactive Analytics & Distribution Charts** — Visualized insights powered by Recharts and D3 for context window distributions, top providers, and model capability matrices.
- 🔑 **Interactive API Key Setup Guides** — Step-by-step instructions and direct portal links to acquire free API keys with zero friction.
- 🔄 **Supabase Real-Time Cloud Sync** — Robust real-time database synchronization with in-memory resilient fallback for uninterrupted uptime.
- 🌐 **Full Bilingual Support & Dark/Light Theme** — Seamless switching between English and Vietnamese interfaces with eye-safe modern dark and light aesthetics.

# Tổng quan
**ZeroLLM** là website tổng hợp toàn diện theo thời gian thực về các nhà cung cấp (Providers) có mô hình ngôn ngữ lớn (LLM) hoàn toàn miễn phí trên thị trường. Được xây dựng cho cuộc thi **Google AI Riser Vietnam 2026** và hỗ trợ toàn diện bởi trợ lý AI **Google Antigravity** cùng **Google AI Studio**, ZeroLLM tập hợp và phân loại các nhà cung cấp API LLM 0 đồng, giúp lập trình viên, nhà nghiên cứu và các nhà sáng tạo dễ dàng tiếp cận các mô hình AI miễn phí mà không gặp rào cản thẻ tín dụng.

> **Lưu ý về định vị:** ZeroLLM là **nền tảng tổng hợp và cung cấp danh mục các Provider có Free LLM Model**, được cập nhật liên tục theo thời gian thực từ mô hình Google Gemini mới nhất (**Gemini-3.7-Flash** / cơ chế tự động nhận diện model Flash tương lai). Đây không phải là trang xếp hạng hay so sánh năng lực mô hình, mà là thư viện thực tế giúp lập trình viên tìm kiếm endpoint và hạn mức API miễn phí.

## Mục đích
### Mục tiêu:
- Tổng hợp và chỉ mục các nhà cung cấp API LLM miễn phí, thông số context window và giới hạn quota (RPM, RPD) trên một giao diện thống nhất.
- Xóa bỏ rào cản tìm kiếm các gói Free Tier uy tín giữa hàng loạt nhà cung cấp như Google AI Studio, Groq, OpenRouter, Mistral, GitHub Models, Cloudflare, Cerebras, SambaNova,...
- Minh chứng cho một giải pháp full-stack hoàn chỉnh được xây dựng theo quy trình "Vibe Coding" hiện đại (**Prompt → Build → Ship**) với **Google Antigravity**, **Google AI Studio** và triển khai trên **Google Cloud Run**.

### Lợi ích:
- **Năng suất:** Tiết kiệm hàng giờ tra cứu thủ công nhờ bảng tổng hợp trực quan về độ dài ngữ cảnh, giới hạn request/phút, request/ngày và cổng đăng ký API của từng nhà cung cấp.
- **Chất lượng:** Tích hợp công cụ quét và xác thực tự động được hỗ trợ bởi **mô hình Google Gemini Flash mới nhất (Gemini-3.7-Flash + Google Search Grounding)** để liên tục rà soát trạng thái hoạt động, tài liệu và các model vừa ra mắt mà không bao giờ bị lỗi thời.
- **Công nghệ:** Kiến trúc full-stack hiện đại với **Next.js 15 (App Router) + TypeScript**, giao diện **Tailwind CSS**, xử lý AI thông minh qua **Google Gemini Flash mới nhất (cơ chế phân giải phiên bản linh hoạt & tìm kiếm web thời gian thực)**, đồng bộ cơ sở dữ liệu với **Supabase**, và vận hành tối ưu trên hạ tầng **Google Cloud Run**.
